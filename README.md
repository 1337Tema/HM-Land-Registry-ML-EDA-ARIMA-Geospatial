# ROSIT2: Анализ и Прогнозирование Цен на Недвижимость в Англии и Уэльсе

Этот проект посвящен анализу данных о продажах недвижимости в Англии и Уэльсе, а также построению моделей для предсказания цен и прогнозирования их динамики во времени.

## 📝 Описание проекта

Проект включает в себя несколько ключевых этапов:

1.  **Исследовательский анализ данных (EDA):** Глубокое изучение данных для выявления тенденций, аномалий, взаимосвязей между признаками и ценой недвижимости.
2.  **Геопространственный анализ:** Обогащение данных геокоординатами и анализ пространственного распределения цен, а также создание гео-признаков.
3.  **Построение моделей машинного обучения:** Разработка регрессионных моделей (LightGBM, XGBoost) для предсказания цены конкретного объекта недвижимости на основе его характеристик.
4.  **Прогнозирование временных рядов:** Использование моделей ARIMA для прогнозирования средней цены недвижимости на несколько лет вперед, как в целом, так и для различных категорий и комбинаций параметров.
5.  **Подготовка данных для BI:** Формирование выходных данных в формате, удобном для визуализации и интерактивного анализа в Power BI.
6.  **Веб-приложение:** Создание простого веб-интерфейса на Flask для интерактивного получения прогнозов цен на основе введенных пользователем параметров.

## 📊 Данные

### Основной датасет: Price Paid Data

В проекте используются данные "Price Paid Data" от HM Land Registry, включающие информацию обо всех зарегистрированных продажах недвижимости в Англии и Уэльсе по полной рыночной стоимости. Адресные данные ограничены уровнем города.

**Источник:** Данные можно найти на [портале gov.uk](https://www.gov.uk/government/statistical-data-sets/price-paid-data-downloads) или в качестве дополнения на [Kaggle: UK Land Registry Transactions](https://www.kaggle.com/hm-land-registry/uk-land-registry-transactions).

**Основные поля датасета:**

*   `Transaction unique identifier`: Уникальный идентификатор транзакции.
*   `Price`: Цена продажи.
*   `Date of Transfer`: Дата завершения продажи.
*   `Property Type`: Тип недвижимости:
    *   `D` = Отдельно стоящий дом (Detached)
    *   `S` = Дом на двух хозяев / Таунхаус с одной общей стеной (Semi-Detached)
    *   `T` = Рядный дом / Таунхаус с двумя общими стенами (Terraced)
    *   `F` = Квартиры/Мезонеты (Flats/Maisonettes)
    *   `O` = Другое (Other)
*   `Old/New`: Возраст недвижимости:
    *   `Y` = Новостройка (Newly built)
    *   `N` = Существующее здание (Established residential building)
*   `Duration`: Срок владения (тенура):
    *   `F` = Полное владение (Freehold)
    *   `L` = Долгосрочная аренда (Leasehold)
    *   *(Примечание: Договоры аренды на срок 7 лет и менее не включаются).*
*   `Town/City`: Город.
*   `District`: Район.
*   `County`: Графство.
*   `PPD Category Type`: Тип транзакции Price Paid:
    *   `A` = Стандартная транзакция (Standard Price Paid entry) - продажа жилой недвижимости по полной рыночной стоимости. Собирается с января 1995.
    *   `B` = Дополнительная транзакция (Additional Price Paid entry) - включает продажи банком заложенного имущества, выкуп для сдачи в аренду, передачу не частным лицам. Идентифицируется с октября 2013.
*   `Record Status` (только в месячных файлах): Статус записи (добавление, изменение, удаление).

### Дополнительные геоданные:

*   `postcode_lat_long.csv`: Координаты (широта, долгота) для почтовых индексов.
*   `city_lat_long.csv`: Координаты (широта, долгота) для городов.

Эти файлы генерируются в процессе работы ноутбука `geospacial.ipynb`.

## 🚀 Начало работы

### Предварительные требования

*   Python 3.9+
*   Установленные зависимости из `requirements.txt`
*   Скачанный датасет `pp-complete.parquet` помещенный в папку `data/`.

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Порядок выполнения ноутбуков

1.  **`geospacial.ipynb` (опционально, если нужны свежие геоданные):**  
    Этот ноутбук использует `pgeocode` и `geopy` для получения координат по почтовым индексам и городам и сохраняет их в `data/postcode_lat_long.csv` и `data/city_lat_long.csv`.  
    *Внимание: геокодирование городов может занять много времени из-за ограничений на количество запросов к API.* Готовые файлы уже есть в репозитории.

2.  **`EDA.ipynb`:**  
    Запустите для проведения исследовательского анализа данных. Помогает понять структуру данных, распределения, выбросы и т.д.

3.  **`main.ipynb`:**  
    Основной ноутбук для обучения моделей машинного обучения (LightGBM, XGBoost) для предсказания цен. Включает feature engineering, предобработку, обучение и оценку моделей. Обученные модели сохранены в папку `model/`.

4.  **`ARIMA.ipynb` (Вариант 1 вывода):**  
    Этот ноутбук выполняет прогнозирование временных рядов средней цены с использованием ARIMA для различных отдельных категорий (общая цена, по типу, по новизне и т.д.). Результаты сохраняются в `output/arima_forecast_results_actual_price.csv` в "широком" формате.

5.  **`ARIMA_BI.ipynb` (Вариант 2 вывода для Power BI):**  
    Этот ноутбук выполняет прогнозирование временных рядов средней цены с использованием ARIMA для **комбинаций** различных параметров. Результаты сохраняются в `output/arima_forecasts_combinations_long.csv` в "длинном" формате, оптимизированном для использования в Power BI.  
    *Внимание: выполнение этого ноутбука может занять значительное время из-за большого количества возможных комбинаций.*

## Запуск веб-приложения

Веб-приложение на Flask позволяет интерактивно получать прогнозы цен.
1. Убедитесь, что файл model/pipeline.joblib существует (сгенерирован main.ipynb).
2. Убедитесь, что файл data/city_lat_long.csv существует (сгенерирован geospacial.ipynb или предоставлен).
3. Перейдите в директорию web/:
```bash
cd project/web 
```
4. Запустите приложение:
```bash
python app.py
```
5. Откройте в браузере адрес http://127.0.0.1:5000/ (или http://localhost:5000/).

## 📈 Результаты и визуализация

### Модели машинного обучения (`main.ipynb`)

*   **Метрики:** RMSLE (Root Mean Squared Logarithmic Error) и MAE (Mean Absolute Error) используются для оценки моделей предсказания цен.
*   **Важность признаков:** Графики важности признаков показывают, какие характеристики недвижимости наиболее сильно влияют на цену.

    ![Пример графика важности признаков](img\feature_importances_lightgbm.png) 

### Прогнозы временных рядов (`ARIMA.ipynb`, `ARIMA_BI.ipynb`)

*   **Графики прогнозов:** Для каждой проанализированной категории или комбинации строятся графики, показывающие исторические данные, прогноз ARIMA и доверительные интервалы.

    ![Пример графика ARIMA](img\ARIMA.png)

*   **Выходные CSV файлы:**
    *   `output/arima_forecast_results_actual_price.csv`: Содержит прогнозы для отдельных категорий в широком формате. Каждая колонка представляет временной ряд для определенной категории.
    *   `output/arima_forecasts_combinations_long.csv`: Содержит прогнозы для комбинаций параметров в длинном формате, готовом для импорта в Power BI. Структура файла: `year`, `param1_name`, `param1_value`, ..., `price_value`, `value_type` ('historical'/'forecast'), `lower_ci`, `upper_ci`.

### Power BI Дашборд

Файл `output/arima_forecasts_combinations_long.csv` предназначен для создания интерактивного дашборда в Power BI. Это позволяет пользователям:

*   Выбирать интересующие комбинации параметров недвижимости с помощью срезов (slicers).
*   Визуализировать динамику средних цен (история + прогноз) для выбранной комбинации.
*   Оценивать неопределенность прогноза с помощью доверительных интервалов.

    ![Пример дашборда Power BI](img\power_bi.png)
